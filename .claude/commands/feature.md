Задача: $ARGUMENTS

Веди задачу через агентов из `.claude/agents/`, по порядку.

1. **План.** Вызови `planner` с текстом задачи. Если он вернул вопросы —
   покажи их мне и остановись.
2. Покажи мне план и дождись подтверждения. Без подтверждения дальше не иди.
3. **Реализация.** Для каждого шага плана по очереди:
   - вызови `implementer` с текстом шага и контрактами из плана;
   - вызови `test-writer` для того, что изменил шаг;
   - вызови `test-runner`. Если тесты упали из-за кода — верни шаг
     `implementer` с отчётом о падении. Не больше двух попыток, дальше —
     ко мне.
4. **Ревью.** Вызови `reviewer` на весь дифф задачи. Находки «критично» и
   «важно» отдай `implementer` на исправление, затем снова `test-runner`.
5. **Итог.** Покажи мне:
   - что сделано по шагам;
   - результат последнего прогона тестов;
   - оставшиеся находки ревью;
   - предложение сообщений коммитов по одному на шаг, на русском, в стиле
     Conventional Commits.
