# Настройки

Настройки лежат в двух местах:

- `config/settings.json` — параметры сервиса. Пример с пояснениями —
  `config/settings.example.json`.
- переменные окружения — пути и то, что удобно менять в Docker. Для
  `docker compose` они задаются в `.env` (пример — `.env.example`).

Переменная окружения важнее значения из файла. Что сервис прочитал в итоге,
показывает `GET /api/config`.

## config/settings.json

Ключи можно писать по-русски или по-английски — сервис понимает оба
варианта. Ключи, начинающиеся с `_`, игнорируются: это пояснения.

### Сервер — `сервер` / `server`

| Ключ | По умолчанию | Описание |
|---|---|---|
| `хост` / `host` | `0.0.0.0` | `127.0.0.1` — только с этой машины |
| `порт` / `port` | `5002` | |
| `отладка` / `debug` | `false` | Режим отладки Flask. Только для разработки |
| `макс_размер_файла` / `max_content_length` | `134217728` | Предел загрузки в байтах; больше — ответ 413 |

### Распознавание — `распознавание` / `ocr`

| Ключ | По умолчанию | Описание |
|---|---|---|
| `язык` / `language` | `ru` | Язык рукописи для свободного текста: `ru`, `en`, `auto` или название языка. У схемы свой — поле `language` |
| `движок` / `backend` | `cli` | Способ вызова модели, см. ниже |
| `таймаут` / `timeout` | `null` | Предел на один проход модели, секунды. `null` — без предела |
| `макс_токенов` / `max_tokens` | `4096` | Предел длины ответа при расшифровке свободного текста |
| `температура` / `temperature` | `0` | При 0 повторный прогон того же файла даёт тот же результат |
| `длина_контекста` / `context_length` | `16384` | Контекст модели |
| `фрагментация` / `fragmentation` | `true` | Проходы по зонам схемы. `false` — один проход на страницу |
| `длинная_сторона` / `target_long_side` | `2200` | До какого размера увеличивать мелкие сканы, пиксели |
| `масштаб_pdf` / `pdf_scale` | `2.0` | Рендер страниц PDF: 2.0 = 144 DPI, 4.0 = 288 DPI |

**Движок.**

- `cli` — каждый проход запускает `llama-mtmd-cli`. Ничего не держит в
  памяти между запросами, но и модель загружает заново на каждый проход.
  Подходит для редких запросов.
- `server` — при первом запросе поднимается `llama-server`, и модель живёт в
  видеопамяти до остановки сервиса. Быстрее под нагрузкой и отдаёт
  вероятности чтения (`logprob_min`). Если `llama-server` не найден или не
  поднялся, сервис продолжает работать через `cli`; что используется на
  деле, показывает `backend` в `/api/status`.

Папочная обвязка `tools/watch_folder.py` поднимает `llama-server` всегда,
независимо от этой настройки; отключается флагом `--no-server`.

### Машина — `машина` / `hardware`

| Ключ | По умолчанию | Описание |
|---|---|---|
| `устройство` / `device` | `auto` | `auto`, `gpu` (или `cuda`), `cpu` |
| `только_cpu` / `force_cpu` | `false` | Считать на CPU, даже если есть GPU |
| `только_gpu` / `force_gpu` | `false` | Требовать GPU и не откатываться на CPU |
| `слои_gpu` / `gpu_layers` | `auto` | Сколько слоёв модели грузить в видеопамять |
| `потоки_cpu` / `cpu_threads` | `auto` | `auto` = ядра − 1 |
| `число_gpu` / `gpu_count` | `1` | |

Автоопределение слоёв идёт по общему объёму видеопамяти:

```
VRAM >= 11 ГБ  ->  99   (вся модель на GPU)
VRAM >=  8 ГБ  ->  35
VRAM >=  4 ГБ  ->  20
нет NVIDIA     ->   0   (CPU)
```

Частичная выгрузка на CPU не только замедляет, но и ухудшает чтение. Если
модель не помещается целиком, возьмите квантизацию поменьше.

### Пути — `пути` / `paths`

| Ключ | По умолчанию | Описание |
|---|---|---|
| `папка_загрузок` / `upload_folder` | `uploads` | Временные файлы запросов |
| `папка_моделей` / `models_folder` | `models` | |
| `файл_модели` / `model_file` | `Qwen2.5-VL-7B-Instruct-Q4_K_M.gguf` | Имя файла в папке моделей |
| `файл_проектора` / `mmproj_file` | `mmproj-Qwen2.5-VL-7B-Instruct-f16.gguf` | |
| `путь_llama` / `llama_executable` | `auto` | `auto` — `llama.cpp/build/bin/llama-mtmd-cli`; иначе полный путь |

Относительные пути отсчитываются от корня проекта.

### API — `апи` / `api`

| Ключ | По умолчанию | Описание |
|---|---|---|
| `включить_cors` / `enable_cors` | `true` | |
| `лимит_запросов.включён` / `rate_limit.enabled` | `false` | Лимит запросов распознавания с одного адреса |
| `лимит_запросов.запросов_в_минуту` / `rate_limit.requests_per_minute` | `10` | |

Счётчик лимита живёт в памяти процесса: при нескольких воркерах предел
окажется кратно выше заявленного.

## Переменные окружения

### Сервис

| Переменная | По умолчанию | Описание |
|---|---|---|
| `SERVER_PORT` | из файла | Порт |
| `SERVER_HOST` | из файла | Хост |
| `LLAMA_BACKEND` | из файла | `cli` или `server` |
| `LLAMA_SERVER_PORT` | `8099` | Порт внутреннего `llama-server` |
| `LLAMA_CLI_PATH` | — | Путь к `llama-mtmd-cli`, если он не в `llama.cpp/build/bin` |
| `MODEL_FILE` | из файла | Имя файла модели |
| `MMPROJ_FILE` | из файла | Имя файла проектора |

### Данные

| Переменная | По умолчанию | Описание |
|---|---|---|
| `SCHEMA_DIR` | `config/schemas` | Директория схем |
| `DICT_DIR` | `data/dictionaries` | Директория словарей |
| `DICT_AUTO_RELOAD` | `1` | `0` — не подхватывать изменения словарей на ходу, только `POST /api/dictionaries/reload` |
| `DICT_AUTO_RELOAD_SEC` | `0` | Проверять директорию словарей не чаще, чем раз в столько секунд |
| `RESULTS_DB` | `data/results.db` | Файл истории распознаваний |
| `RESULTS_DB_ENABLED` | `1` | `0` — историю не вести |

### Журналы

| Переменная | По умолчанию | Описание |
|---|---|---|
| `LOG_DIR` | `logs` | Директория журналов |
| `LOG_LEVEL` | `DEBUG` | Уровень записи в `app.log` |
| `LOG_CONSOLE_LEVEL` | `INFO` | Уровень вывода в консоль |
| `LOG_MAX_BYTES` | `52428800` | Размер файла до ротации |
| `LOG_BACKUP_COUNT` | `10` | Сколько старых файлов `app.log` и `errors.log` хранить |
| `AUDIT_BACKUP_COUNT` | `50` | То же для `audit.jsonl` |
| `AUDIT_LOG_CONTENT` | `1` | `0` — в аудит идут только метаданные, без распознанного содержимого |
| `LOG_RAW_MODEL_OUTPUT` | `0` | `1` — сохранять сырой ответ модели по каждому проходу в `logs/raw/` |

### Docker

| Переменная | По умолчанию | Описание |
|---|---|---|
| `GPU_COUNT` | `1` | Сколько GPU отдать контейнеру, число или `all` |
| `CUDA_VISIBLE_DEVICES` | `0` | Какие GPU видны контейнеру |
| `TZ` | `UTC` | Часовой пояс меток времени |

## Журналы

| Файл | Формат | Что в нём |
|---|---|---|
| `app.log` | JSON Lines | Ход работы: каждый вызов модели, каждое решение словаря, каждое голосование |
| `audit.jsonl` | JSON Lines | По записи на распознанную страницу: что пришло, что вернули |
| `errors.log` | Текст | Предупреждения и ошибки со стектрейсами |

Все записи одного запроса связаны `request_id`:

```bash
grep '"request_id": "a3f2c1d0"' logs/app.log | jq -c '{event, field, recognized, result}'
scripts/logs.sh errors 50
```

## Данные и приватность

Распознанное содержимое документов сохраняется в трёх местах:

| Где | Что | Как отключить |
|---|---|---|
| `data/results.db` | Текст, поля, трассировка | `RESULTS_DB_ENABLED=0` |
| `logs/audit.jsonl` | То же, по записи на страницу | `AUDIT_LOG_CONTENT=0` |
| `logs/app.log`, консоль | Значения полей в записях о решениях словаря и голосовании | `LOG_LEVEL=WARNING` и `LOG_CONSOLE_LEVEL=WARNING` |
| `logs/errors.log` | Первые 300 символов ответа модели, если он не разобрался как JSON | Не отключается |

Загруженный файл удаляется сразу после обработки. Сырой ответ модели в
`logs/raw/` пишется только при `LOG_RAW_MODEL_OUTPUT=1`.
