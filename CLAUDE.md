# CLAUDE.md

Сервис распознавания рукописного текста: Qwen2.5-VL через llama.cpp, HTTP API
на Flask и веб-интерфейс. Всё работает локально: документы не покидают машину.

## Как устроена работа

Задачи веду я. Агенты в `.claude/agents/` — исполнители с узкой ролью:

| Агент | Роль | Права |
|---|---|---|
| `planner` | Разбивает задачу на шаги, находит затронутые модули | Только читает |
| `implementer` | Делает один шаг плана | Правит код |
| `test-writer` | Пишет модульные тесты | Правит только `tests/` |
| `test-runner` | Прогоняет тесты и разбирает падения | Запускает и читает |
| `reviewer` | Ревью диффа перед коммитом | Только читает |

Полный цикл задачи — `/feature <описание>`, отдельные шаги — `/test` и
`/review`.

Правила:

- Агенты не коммитят и не пушат. Коммит делаю я после ревью.
- Один шаг плана — один коммит.
- Реальные документы, сканы и журналы агентам не показываются: путь закрыт в
  `.claude/settings.json`. Для проверок — синтетические картинки.

## Структура (план)

```
src/        сервис: пайплайн распознавания, API, хранилище
tools/      обвязка вокруг сервиса
config/     настройки и схемы документов
data/       словари
tests/      модульные тесты
scripts/    запуск, остановка, журналы
docs/       документация
```

## Соглашения

- Python 3.11.
- Комментарии и сообщения коммитов — на русском. Коммиты в стиле Conventional
  Commits: `feat(ocr): ...`, `fix(storage): ...`, `test(api): ...`.
- Ветки: `feature/<область>`, `test/<область>`, `docs/...`; в `main` —
  слиянием без fast-forward.
- Сервис не выдумывает: пустое поле остаётся пустым, сомнительное уходит на
  ручную проверку. То же требование к коду постобработки: не «чинить»
  значение молча.
